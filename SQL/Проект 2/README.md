### Team 00 — Traveling Salesman Problem (SQL Bootcamp)

В рамках командного проекта решала задачу коммивояжёра (TSP) с использованием SQL на PostgreSQL.

- Создала таблицу для хранения городов, маршрутов и стоимости перемещений между ними.
- Реализовала поиск маршрутов с посещением всех городов и возвращением в исходную точку.
- Использовала рекурсивные SQL-запросы для перебора возможных маршрутов.
- Определила маршруты с минимальной и максимальной стоимостью поездки.

**Технологии:** PostgreSQL, SQL, Recursive CTE, JOIN, агрегатные функции.
