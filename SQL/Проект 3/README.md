### Day 09 — RDBMS Is Not Just Tables (SQL Bootcamp)

В рамках проекта работала с функциями и триггерами базы данных PostgreSQL для автоматизации обработки данных.

- Создала систему аудита изменений данных с использованием триггеров для операций INSERT, UPDATE и DELETE.
- Реализовала автоматическое сохранение истории изменений записей в отдельной таблице.
- Разработала пользовательские SQL-функции с параметрами для фильтрации и обработки данных.
- Использовала PL/pgSQL для создания функций с условиями и бизнес-логикой.
- Реализовала функции для поиска минимального значения в массиве и генерации последовательности Фибоначчи.

**Технологии:** PostgreSQL, SQL, PL/pgSQL, Triggers, Functions, DDL, DML.
