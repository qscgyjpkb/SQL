### Team 01 — Data Warehouse (SQL Bootcamp)

В рамках проекта работала с хранилищем данных (DWH) на PostgreSQL.

- Агрегировала финансовые транзакции пользователей по типам баланса и валютам.
- Обрабатывала пропущенные значения и несогласованные данные из разных источников.
- Рассчитывала суммы транзакций в долларах США с учётом валютных курсов.
- Реализовала SQL-запросы для поиска актуального курса валюты на дату транзакции с использованием исторических данных.

**Технологии:** PostgreSQL, SQL, JOIN, GROUP BY, CTE.
