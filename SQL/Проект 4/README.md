### Day 08 — Transactions & Isolation Levels (SQL Bootcamp)

В рамках проекта изучила работу транзакций и уровней изоляции данных в PostgreSQL.

- Работала с параллельными транзакциями в нескольких сессиях базы данных.
- Исследовала уровни изоляции READ COMMITTED, REPEATABLE READ и SERIALIZABLE.
- Воспроизвела и проанализировала аномалии Lost Update, Non-Repeatable Read и Phantom Read.
- Проверила влияние уровней изоляции на согласованность данных и видимость изменений между транзакциями.
- Смоделировала ситуацию взаимной блокировки (Deadlock) при одновременном изменении данных.

**Технологии:** PostgreSQL, SQL, Transactions, ACID, COMMIT, Isolation Levels, psql.
