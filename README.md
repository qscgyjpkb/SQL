# SQL Bootcamp | Школа 21

Этот репозиторий содержит часть моих учебных проектов, выполненных в рамках SQL Bootcamp в **Школе 21 от Сбера**.

В ходе обучения я работала с реляционными базами данных PostgreSQL, осваивала SQL и решала практические задачи по обработке, анализу и управлению данными.

**Основные направления работы:**
- **Анализ данных:** написание SQL-запросов, объединение таблиц, фильтрация, группировка и агрегация данных.
- **Хранилища данных (DWH):** обработка данных из разных источников, работа с историческими данными и валютными курсами.
- **Алгоритмы:** решение задачи коммивояжёра с использованием рекурсивных SQL-запросов.
- **Транзакции:** изучение уровней изоляции, согласованности данных и механизмов блокировок.
- **Автоматизация:** создание пользовательских функций, триггеров и системы аудита изменений данных.

**Технологии и инструменты:** PostgreSQL, SQL, PL/pgSQL, Git, GitLab.

### О репозитории

Здесь представлены **не все выполненные мной задания, а избранные проекты**, демонстрирующие различные навыки работы с базами данных.

Каждый проект находится в отдельной папке и содержит SQL-скрипты с решениями практических задач.
